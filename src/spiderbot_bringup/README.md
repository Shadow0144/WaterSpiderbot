# spiderbot_bringup

Provides launch files for quickly starting up a Spiderbot stack

## Launch files

- spiderbot_real.launch.xml
 Launchs all the nodes required for running the Spiderbot stack on a real, physical Spiderbot
- spiderbot_simulation_teleop.launch.xml
 Launchs all the nodes required for running a simulation of a Spiderbot in production mode and teleoperating it
 - spiderbot_simulation_training.launch.xml
 Launchs all the nodes required for running a simulation for training a Spiderbot
