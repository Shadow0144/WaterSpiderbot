# spiderbot_bringup

Provides launch files for quickly starting up a Spiderbot stack

## Launch files

- spiderbot_real.launch.xml
 Launchs all the nodes with parameters required for running the Spiderbot stack on a real, physical Spiderbot
- spiderbot_simulation.launch.xml
 Launchs all the nodes with parameters required for running a simulation of a Spiderbot
